# Gils English School SaaS
Projet Ylice & OTK - 50/50

## Frontend (Ylice) — Next.js 14

Scaffold du frontend avec les 4 modules d'Ylice : Test Niveau + Paiement, Bulletin, Finance Cachée, Dashboard Boss.
L'authentification et les données sont mockées en local en attendant l'API Spring Boot d'Othniel.

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000). Comptes de démonstration :

- Boss : `boss@gils.com` / `boss123` (accès aux 4 modules)
- Staff : `staff@gils.com` / `staff123` (Test Niveau + Bulletin uniquement)
